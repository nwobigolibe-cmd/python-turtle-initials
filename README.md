## Originally developed:

2024–2025

## Overview

A Python graphics program that uses the Turtle module to draw an approximation of my initials in a graphical window. The program controls the turtle's movement, pen colour, pen size and drawing speed to create the design.

## Features

- Opens a graphical window with a pink background.
- Sets the window title to identify the initials being drawn.
- Uses a turtle object to draw the letters.
- Controls pen colour, pen size and drawing speed.
- Uses movement, rotation and circular drawing commands to create the design.

## Technologies

- Python
- Turtle Graphics Module
- Coordinate-Based Drawing

## Concepts Demonstrated

- Basic graphics programming.
- Sequential instructions and control flow.
- Using a standard Python library.
- Coordinate positioning and directional movement.
- Translating a visual design into program instructions.

## How to Run

1. Ensure Python 3 is installed.
2. Save the program as `main.py`.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

A graphical window will open displaying the drawing.
